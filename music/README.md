# マシュ・リリスの音楽放送局 — ホーム画面用ページ（PWA）

iPhone のホーム画面に追加するとアプリ風アイコンで開ける、音楽放送局の案内ページ。
回のリストと曲目を表示し、各回の YouTube プレイリストへ案内する。

## リンクの差し替え方法

すべて `index.html` の中、`<script>` 冒頭の `EPISODES` 配列が設定場所。

- **第1回を有効化する**：第1回の行の `playlistUrl: ""` を、プレイリストの URL に変えるだけ。
  「プレイリスト準備中」表示が「YouTubeプレイリストで聞く」ボタンに変わる。
- **新しい回を足す**：`EPISODES` 配列に、コメントで書いてある雛形どおりに行を1つ足す
  （`no` / `date` / `title` / `note` / `corner` / `tracks` / `playlistUrl`）。

## 構成

- `index.html` — 本体（回の設定もここ）
- `manifest.json` — PWA マニフェスト（standalone 表示、テーマカラー等）
- `sw.js` — 最小のサービスワーカー（シェルのキャッシュ）
- `icons/icon-180.png` — apple-touch-icon 用
- `icons/icon-192.png` / `icons/icon-512.png` — マニフェスト用
